# FEALPy | Development Task | 新 mesh 模块开发总任务 | 对象边界

- **任务编号**：new_mesh_module
- **任务类型**：Development Task
- **边界结论**：本任务负责 01~08 任务网络下的新 mesh 模块开发治理与阶段收口，不替代单个子任务内部实现细节

## 一、任务内范围

总任务范围内必须处理以下对象：

- 子任务网络定义与依赖关系维护（01~08）
- 阶段交接物定义（输入、输出、判据）
- 关键回流规则（迁移改动触发补测、查漏触发回流）
- 阶段收口口径与最终验收组织

## 二、任务外范围

以下内容不由总任务直接承担：

- 单个算法实现细节与具体代码设计裁决
- 单个测试用例的断言级实现选择
- 子任务内部的日常执行排期与个人分工微调
- 与本网络无关的跨模块重构

## 三、与子任务的职责分界

- 总任务负责定义 What 侧网络与阶段目标。
- 子任务负责各自对象内的设计、实现、验证和执行 How。
- 总任务可提出回流要求，但不替代子任务的技术实现主位。

## 四、边界纪律

- 不将目录结构或文件命名直接等同为任务成立。
- 不将 08 最终验收提前替代 07 的系统查漏。
- 不将 06 的覆盖率指标化工作替代真实风险验证。
- 不将总任务文档写成对子任务实现细节的混合说明。
