# FEALPy | 网格模块约定

## 一、文件结构

```text
mesh/
	#---------- 核心骨架 ----------#
	schema/                   # 形状格式 | 存放实体算法
		classic/                  # 经典低阶形状
			...
		entity_schema.py          # 基类
		registry.py               # 提供 名字-形状类 映射
		utils.py                  # 工具函数
	
	stoarge/                  # 网格存储 | 存放网格数据结构
		mesh_storage.py           # 网格数据结构
		relation.py               # 拓扑关系存储结构
	
	view/                     # 计算视图 | 定义用户接口
		entity_view.py            # 实体视图
		mesh.py                   # 网格视图
		fealpy_api.py             # 老接口兼容性视图
	
	#---------- 算法类 ----------#	
	topology/                 # 算法：拓扑构造、推断
		boundary.py               # 边界实体推断
		builder.py                # 网格构造（construct）算法、拓扑关系推导
	
	ipoints.py                # 算法：插值点位置、全局编号、全局映射
	join.py                   # 算法：简单合并网格
	merge.py                  # 算法：按距离合并重复点
	transform.py              # 算法：参考单元到物理单元变换
	uniform_refine.py         # 算法：均匀加密
	
	#---------- 工具类 ----------#
	plotting/                 # 工具：基于 Matplotlib 的网格绘图
		artist.py
		classic.py
	
	vtk_writter.py            # 工具：VTK 存储
	vtk_reader.py             # 工具：VTK 读取
	
	#---------- 兼容层 ----------#
	factory.py                # 提供 TriangleMesh 等类
	mesh_base.py              # 提供 SimplexMesh 等类
```

> [!INFO] 基本骨架
> 形成 Mesh 模块核心骨架的，是 `schema/`、`storage/` 和 `view/`。

## 二、算法的分类与实现

在接下来的叙述中，我们约定：

- 算法按作用范围是否仅限于单一实体形状，分为**实体算法**和**网格算法**；
- 算法对应函数按接口的位置，分为**实体视图方法**、**网格视图方法**和**外部函数**。

例如，计算形函数是实体算法，网格加密是网格算法。

我们通常对算法的实现方式做如下约定：

**实体算法**

| 情形                | 算法实现             | 算法接口        |
| ----------------- | ---------------- | ----------- |
| 对所有实体类型有统一实现      | 放入 Schema 的适当基类内 | 实体视图，可选网格视图 |
| 几乎所有实体类型支持，但实现不统一 | 放入具体 Schema 中    | 实体视图，可选网格视图 |
| 理论层面仅少数实体类型能支持    | 放入具体 Schema 中    | 实体视图，可选网格视图 |

**网格算法**

| 情形                | 算法实现 | 算法接口            |
| ----------------- | ---- | --------------- |
| 对所有网格类型有统一实现      | 外部函数 | 外部函数，可选网格视图方法   |
| 几乎所有网格类型支持，但实现不统一 | 外部函数 | 多个外部函数，可选网格视图方法 |
| 理论层面仅少数网格类型能支持    | 外部函数 | 外部函数            |

## 三、计算视图

针对网格视图 `Mesh` 和实体视图 `EntityView`，我们约定：

**3.1 视图是接口**

视图不是算法实现的载体，不能在视图类中实现数学算法。

**3.2 视图是外壳**

视图在初始化时只能做属性赋值。
