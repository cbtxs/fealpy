# FEALPy | 网格模块约定

## 一、算法的分类与实现

在接下来的叙述中，我们约定：

- 算法按作用范围是否仅限于单一实体形状，分为**实体算法**和**网格算法**；
- 算法对应函数按接口的位置，分为**实体视图方法**、**网格视图方法**和**外部函数**。

例如，计算形函数是实体算法，网格加密是网格算法。

我们通常对算法的实现方式做如下约定：

**实体算法**

| 情形                | 算法实现             | 算法接口            |
| ----------------- | ---------------- | --------------- |
| 对所有实体类型有统一实现      | 放入 Schema 的适当基类内 | 实体视图方法，可选网格视图方法 |
| 几乎所有实体类型支持，但实现不统一 | 放入具体 Schema 中    | 实体视图方法，可选网格视图方法 |
| 理论层面仅少数实体类型能支持    | 放入具体 Schema 中    | 实体视图方法，可选网格视图方法 |

**网格算法**

| 情形                | 算法实现 | 算法接口            |
| ----------------- | ---- | --------------- |
| 对所有网格类型有统一实现      | 外部函数 | 外部函数，可选网格视图方法   |
| 几乎所有网格类型支持，但实现不统一 | 外部函数 | 多个外部函数，可选网格视图方法 |
| 理论层面仅少数网格类型能支持    | 外部函数 | 外部函数            |
